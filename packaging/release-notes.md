rippl 1.0.0: the first release, for Linux, macOS and Windows.

**Install**

- macOS and Linux: `curl -fsSL https://ripplbrowser.web.app/install.sh | sh`
- Windows: download `rippl-windows-x64-setup.exe` below and run it.

On Linux rippl is the GTK 4 build on WebKitGTK, as a Flatpak. On macOS it runs on the system's WebKit, and on Windows on WebView2 (Edge's engine, part of Windows). The Mac app is signed for this computer only, not by Apple, so the first time macOS may ask you to confirm opening it (System Settings › Privacy & Security). On Windows, SmartScreen may say the installer is from an unknown publisher: choose More info › Run anyway.
